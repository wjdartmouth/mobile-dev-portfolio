# Spot Journal (Android)

Photo + note + map-pin journal. Uses Room, Photo Picker / Camera, Fused Location, and an OpenStreetMap Leaflet WebView (no Google Maps API key).

## Features
- List + search + delete
- Map tab with OSM tiles and markers
- Capture current location (permission-gated)
- Persist photos under app files

## Open
Android Studio → Open → `Android/SpotJournal`

```bash
cd Android/SpotJournal && ./gradlew :app:assembleDebug
```
